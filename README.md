# Анализ финансовых транзакций

Сервис для анализа финансовых операций пользователя с возможностью получения отчётов по расходам, поступлениям, курсам валют и ценам акций. 
Данные загружаются из Excel-файла и обрабатываются с помощью `pandas`. 
Результаты возвращаются в формате JSON для дальнейшего использования в веб-приложении или визуализации.
