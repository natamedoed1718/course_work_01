# Курсовой проект: Анализ финансовых транзакций

## Описание проекта
Данный проект реализует анализ финансовых операций пользователя с помощью Python.  
Проект позволяет получать отчёты по расходам, поступлениям, курсам валют и ценам акций, формируя удобный JSON-ответ для дальнейшего использования в веб-приложении или визуализации.

## Цели проекта
- Разобраться с обработкой и анализом данных в `pandas`.
- Получить навыки работы с API для получения курсов валют и цен акций.
- Научиться структурировать проект на функции и модули.
- Настроить тестирование с помощью `pytest`, включая использование `mock` и фикстур.

## Основные функциональные возможности
1. Подсчёт расходов по картам и категориям.
2. Определение топ-транзакций по сумме.
3. Формирование топ-N категорий расходов и доходов.
4. Отдельный учёт переводов и наличных.
5. Получение курсов валют и цен акций через API.
6. Формирование периодов анализа: неделя, месяц, год, все данные до даты.

## Используемые технологии
- `pandas` — работа с таблицами и данными.
- `requests` — запросы к API.
- `datetime` — работа с датой и временем.
- `logging` — логирование событий.
- `pytest` — тестирование.
- `unittest.mock` — мокирование API для тестов.

## 3. Модуль `reports.py`

Модуль `reports.py` содержит функциональность для формирования аналитических отчетов по транзакциям. 
Все отчеты реализованы с использованием библиотеки `pandas`, а также включают логирование и работу с датами.

Дополнительно реализован декоратор, который автоматически сохраняет результаты отчетов в файл.

### Декоратор сохранения отчетов

В модуле реализован декоратор `report_to_file`, который записывает результат выполнения функции-отчета в JSON-файл.

***Возможности:***

* Без параметров — сохраняет в файл по умолчанию `report.json`
* С параметром — позволяет указать имя файла

***Пример использования:***
````
@report_to_file()
def spending_by_category(...):
    ...
````

### Отчет: Траты по категории
````
def spending_by_category(
    transactions: pd.DataFrame,
    category: str,
    date: Optional[str] = None
) -> pd.DataFrame:
````

***Описание:***

Функция возвращает все траты по заданной категории 
за последние 3 месяца относительно переданной даты.

**Если дата не указана — используется текущая дата.**

***Логика работы:***

* Определяется диапазон последних 3 месяцев
* Фильтруются только расходы (`Сумма операции < 0`)
* Фильтрация по категории
* Возвращается `DataFrame` с результатом

### Отчет: Траты по дням недели
````
def spending_by_weekday(
    transactions: pd.DataFrame,
    date: Optional[str] = None
) -> pd.DataFrame:
````

***Описание:***

Функция рассчитывает средние траты для каждого дня недели за последние 3 месяца.

***Логика работы:***

* Определяется диапазон последних 3 месяцев
* Фильтруются только расходы
* Добавляется поле `weekday`
* Группировка по дням недели
* Вычисляется среднее значение трат

***Пример структуры результата:***
````
-weekday-	  -Сумма операции-
Monday	           1200
Tuesday	           950
````
