# Курсовой проект: Анализ финансовых транзакций

## Описание проекта
Данный проект реализует анализ финансовых операций пользователя с помощью Python.  
Проект позволяет получать отчёты по расходам, поступлениям, курсам валют и ценам акций, формируя удобный JSON-ответ для дальнейшего использования в веб-приложении или визуализации.

## Цели проекта
- Разобраться с обработкой и анализом данных в `pandas`.
- Получить навыки работы с API для получения курсов валют и цен акций.
- Научиться структурировать проект на функции и модули.
- Настроить тестирование с помощью `pytest`, включая использование `mock` и фикстур.

## Основные функциональные возможности
1. Подсчёт расходов по картам и категориям.
2. Определение топ-транзакций по сумме.
3. Формирование топ-N категорий расходов и доходов.
4. Отдельный учёт переводов и наличных.
5. Получение курсов валют и цен акций через API.
6. Формирование периодов анализа (неделя, месяц, год, все данные до даты).

## Используемые библиотеки
- `pandas` — работа с таблицами и данными.
- `requests` — запросы к API.
- `datetime` — работа с датой и временем.
- `logging` — логирование событий.
- `pytest` — тестирование.
- `unittest.mock` — мокирование API для тестов.

## Запуск проекта

```
2. Установите зависимости:

```

## 1. Модуль views.py
### Страница «Главная»
***Функция***
```
def main(date_time: str) -> str
```
**Возвращает JSON:**
* приветствие
* расходы по картам
* кешбэк (1% от расходов)
* топ-5 транзакций
* курсы валют
* цены акций

***Пример ответа***
```
{
  "greeting": "Добрый день",
  "cards": [
    {
      "last_digits": "1234",
      "total_spent": 1500.0,
      "cashback": 15.0
    }
  ],
  "top_transactions": [],
  "currency_rates": [],
  "stocks_prices": []
}
```

### Страница «События»
***Функция***
```
def get_events(date_time: str, period: str = "M") -> dict
```

**Периоды**
```
Значение	Описание
W	        неделя
M	        месяц
Y	        год
ALL	        всё время
```
**Возвращает:**

Расходы:
* общая сумма
* топ-7 категорий + "Остальное"
* переводы и наличные

Доходы:
* общая сумма
* категории доходов

Дополнительно:
* валюты
* акции

## 2. Модуль services.py
### Выгодные категории повышенного кешбэка

***Функция***
```
def analyze_cashback(data: pd.DataFrame, year: int, month: int) -> str
```

***Логика:***
* фильтрация по дате
* только расходы с кешбэком
* группировка по категориям
* расчет: 1 рубль за каждые 100 рублей

***Пример:***
```
{
  "Супермаркеты": 17,
  "Фастфуд": 25
}
```

### Инвесткопилка
***Функция***
```
def investment_bank(month: str, transactions: List[Dict[str, Any]], limit: int) -> float
```

***Логика:***

* фильтр по месяцу
* только расходы
* округление вверх до limit
* накопление через reduce

***Пример:***
```
investment_bank("2021-04", transactions, 50)
 → 38.0
```
