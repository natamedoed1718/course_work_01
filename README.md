# Курсовой проект: Анализ финансовых транзакций

## Описание проекта
Данный проект реализует анализ финансовых операций пользователя с помощью Python.  
Проект позволяет получать отчёты по расходам, поступлениям, курсам валют и ценам акций, формируя удобный JSON-ответ для дальнейшего использования в веб-приложении или визуализации.

## Цели проекта
- Разобраться с обработкой и анализом данных в `pandas`.
- Получить навыки работы с API для получения курсов валют и цен акций.
- Научиться структурировать проект на функции и модули.
- Настроить тестирование с помощью `pytest`, включая использование `mock` и фикстур.

## Основные функциональные возможности
1. Подсчёт расходов по картам и категориям.
2. Определение топ-транзакций по сумме.
3. Формирование топ-N категорий расходов и доходов.
4. Отдельный учёт переводов и наличных.
5. Получение курсов валют и цен акций через API.
6. Формирование периодов анализа (неделя, месяц, год, все данные до даты).

## Используемые библиотеки
- `pandas` — работа с таблицами и данными.
- `requests` — запросы к API.
- `datetime` — работа с датой и временем.
- `logging` — логирование событий.
- `pytest` — тестирование.
- `unittest.mock` — мокирование API для тестов.

## Запуск проекта
1. Клонируйте репозиторий:
```bash
git clone <URL_репозитория>
cd coursework_1
```
2. Установите зависимости:
````
pip install -r requirements.txt
````
3. Запустите тесты:
````
pytest --cov tests
````
4. Для проверки работы функций используйте main.py:

````
python src/main.py
````
